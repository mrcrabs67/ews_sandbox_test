# Ticket Workspace Sandbox

Песочница рабочего места оператора поддержки.  
Приложение позволяет просматривать очередь заявок (тикетов), детальную информацию, изменять статус и пользоваться командной палитрой. Все данные имитируются в памяти (мок‑API).

## Технологии

- React 19 + TypeScript
- Redux Toolkit (RTK Query)
- React Router v7
- Material UI v7
- Vite + Vitest

## Запуск проекта

```bash
npm install
npm run dev      # dev‑сервер (http://localhost:5173)
npm run build    # production‑сборка
npm test         # запуск тестов
npm run test:watch  # тесты в режиме наблюдения

src/
├── app/                  # Общая оболочка приложения
│   ├── command-palette/  # Командная палитра (generic runtime)
│   ├── router/           # Маршрутизация
│   ├── store/            # Redux‑store
│   └── theme/            # Провайдер тем
├── modules/              # Бизнес‑фичи
│   ├── tickets/          # Модуль заявок
│   │   ├── api/          # RTK Query API и моковые данные
│   │   ├── model/        # Типы, мапперы, селекторы
│   │   └── ui/           # Компоненты страниц
│   └── workspace/        # Рабочее место оператора
│       ├── commands/     # Ticket‑aware команды
│       ├── state/        # Хранение недавних заявок
│       └── ui/           # Оболочка (shell)
├── shared/               # Переиспользуемые утилиты
│   ├── api/              # Базовый API
│   ├── browser/          # Безопасный доступ к localStorage
│   └── testing/          # Хелперы для тестов
└── test/                 # Настройки тестов 
```

## Основной функционал

- Просмотр очереди заявок с фильтром по статусу.

- Карточка заявки с возможностью редактирования черновика и смены статуса.

- Командная палитра (Ctrl/Cmd+K): переключение темы, переход к списку, отметка заявки как проверенной.

- Блок «Recently opened» на странице списка — три последние открытые заявки из localStorage.
